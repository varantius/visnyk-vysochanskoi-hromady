# Бот новин Височанської громади

Раз на годину перевіряє сайт громади, знаходить нові документи,
визначає яких населених пунктів вони стосуються, і публікує
в Telegram-канал з хештегами.

## Запуск локально

    npm install
    export GEMINI_API_KEY=...
    npm run dry        # перевірка: нічого не надсилає, лише друкує

Коли результат влаштовує:

    export BOT_TOKEN=...
    export CHANNEL=@your_channel
    npm start

Перший запуск нічого не надсилає — лише запам'ятовує поточні документи.

## Запуск на GitHub Actions

Додай у Settings → Secrets and variables → Actions три секрети:
BOT_TOKEN, CHANNEL, GEMINI_API_KEY.

## Якщо перестало працювати

У логах "Нашли документов: 0" — змінилась вёрстка сайту.
Правити селектор у функції fetchDocuments() у index.js.
